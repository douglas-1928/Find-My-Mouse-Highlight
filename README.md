## Overview

**PowerToys Mouse Utilities** — Locate your cursor and highlight clicks during demos. It runs on **Windows** and is distributed under the **MIT** license.

If you searched for *"find my mouse"*, this is the tool you are looking for. Below you will find a feature breakdown, platform-by-platform installation instructions, a quick-start example, and answers to the most common questions.

- Great for presentations
